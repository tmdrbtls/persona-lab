# D 시안 · Cosmos Inspired 디자인 기록

## 기준과 해석

- **주 레퍼런스:** 사용자가 첨부한 `refero.design e6624159-7866-4a06-9a02-a6e367560a85.jpg`. 흰 캔버스, 검은 대형 제목, 중앙의 짧은 설명과 CTA, 주변에 흩어진 작은 이미지 카드, 넓은 여백을 시각적 기준으로 삼았다.
- [Supahero · Superpower](https://supahero.io/hero/superpower): 이미지 중심의 첫 화면이라는 참고점. PersonaLab에서는 이미지 장식을 실제 테스트로 들어가는 카드로 바꾼다.
- [Mubien](https://mubien.com/), [Atelier Meridien](https://atelier-meridian-site.webflow.io/), [Griflan Labs](https://labs.griflan.com/): 사용자가 지정한 모션 참고. 현재 환경에서는 세 사이트의 실제 동작을 브라우저로 재생·측정할 수 없었다. Griflan Labs의 공개 페이지에는 작업물을 조감도로 탐색한다는 설명이 있다. 구체적인 애니메이션을 관찰했다고 주장하지 않고, 사용자 요청에 명시된 포인터·호버·스크롤 반응을 독자적으로 구현한다.
- Refero MCP Styles/Screens/Flows 도구는 이 세션에 연결되지 않았다. Refero Design 스킬의 레퍼런스 고정·결정 기록·시각 QA 절차를 적용한다.

## 레퍼런스 고정

| 결정 | 근거 | 적용 |
|---|---|---|
| 흰 화면과 거의 검은 글자, 큰 제목 | 첨부 Cosmos 이미지 | 히어로에서 텍스트가 중심. 다른 제품 화면도 검은 버튼과 얇은 경계를 사용 |
| 화면 가장자리의 작은 제품 이미지 카드 | 첨부 이미지·Supahero | 카드마다 실제 테스트 상태와 진입 동작을 연결 |
| 포인터·스크롤 반응과 부드러운 호버 | 사용자 요청·Refero 모션 지침 | 미세한 시차와 상승 피드백. 사용자 움직임 줄이기 설정을 존중 |
| 단계별 설정과 근거 탐색 | 기획서·개발_계획서·기존 통합 UI | 제품·프로토타입 → 패널 → Ask/Act → Report → Evidence 유지 |
| 색의 역할 제한 | 첨부 이미지 | 검정은 글자·주 CTA, 색은 카드 속 서로 다른 앱 미리보기에만 사용 |

첫 화면의 제품 이미지는 실제 업로드 이미지가 있으면 이를 표시한다. 기존 예시 테스트에는 이미지 원본이 없으므로 각 앱의 목적을 보여주는 코드 기반 작은 프로토타입 프리뷰를 사용한다. 이는 실제 앱 스크린샷이라는 주장을 하지 않는다.

## 데이터 및 범위

기존 예시 테스트의 이름·상태·지표 정의를 유지한다. 새 테스트는 기존 통합 UI의 브라우저 저장 및 규칙 기반 Ask/Act 시뮬레이션을 사용한다. LLM, Figma API, 실제 참가자 수집, 검증된 예측 정확도는 제공하지 않으며 UI에서 데모임을 표시한다.
