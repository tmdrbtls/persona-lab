# 프론트엔드 디자인 및 협업 메모

## 디자인 원칙

- 자주 사용되는 웹사이트와 완성도 높은 서비스의 UI/UX를 참고한다.
- 레이아웃, 정보 구조, 사용자 흐름, 인터랙션 패턴을 분석하여 PersonaLab에 맞게 적용한다.
- AI에 자유로운 디자인 반복 생성을 맡기는 방식은 지양한다.

## 도구 및 코드 협업 원칙

- Stitch, Google AI Studio, Codex 중 특정 도구를 강제하지 않는다. 담당자가 편한 도구를 사용한다.
- 다른 프론트 팀원이 쉽게 이어서 작업할 수 있도록 결과물을 공유 가능한 코드와 구조로 정리한다.
- 최종 구현물은 공용 GitHub 코드베이스에서 관리하며, 특정 AI 도구 안에만 결과물을 두지 않는다.
- 기존 프로젝트 구조와 호환되게 개발한다. 공통 컴포넌트와 페이지 구조를 지나치게 개인화하지 않는다.

## 적용 전 확인 사항

- 주요 디자인 레퍼런스 웹사이트
- 현재 배포된 프론트에서 우선 수정할 부분
- Stitch와 Google AI Studio의 실제 활용 범위
- 기존 코드 구조와 새 디자인 적용 방식
