# 2026-09-29 회의록

## 진행 현황

- PRD를 바탕으로 프론트엔드 1차 구현과 배포를 완료했다.
- GitHub와 Vercel을 연동하여 배포 중이다.
- 현재 로컬 프로젝트 폴더를 기준으로 Codex를 사용해 개발하고 있다.

## 논의 및 확정 사항

### 프론트 디자인 방향

- 사람들이 자주 사용하는 웹사이트와 완성도 높은 서비스의 UI/UX를 디자인 레퍼런스로 활용한다.
- AI에게 자유롭게 디자인을 반복 생성시키는 방식은 지양한다.
- 레퍼런스의 레이아웃, 정보 구조, 사용자 흐름, 인터랙션 패턴을 검토하고 PersonaLab에 맞게 적용한다.

### 도구 및 협업 방식

- Stitch, Google AI Studio, Codex 중 특정 도구를 사용하도록 강제하지 않는다. 담당자는 편한 도구를 선택할 수 있다.
- 어느 도구를 사용하든 다른 프론트 팀원이 쉽게 이어서 작업할 수 있도록 구현한다.
- 최종 구현물은 공용 GitHub 코드베이스를 기준으로 관리한다. 특정 AI 도구 안에만 존재하는 결과물은 지양한다.
- 기존 프로젝트 구조와 호환되는 방식으로 개발하며, 공통 컴포넌트와 페이지 구조를 지나치게 개인화하지 않는다.

## 추후 확인 사항

- 주요 디자인 레퍼런스로 사용할 웹사이트 선정
- 현재 배포된 프론트에서 우선 수정할 부분 선정
- Stitch와 Google AI Studio의 실제 작업 활용 범위
- 기존 코드 구조를 확인한 뒤 새 디자인을 적용할 방식
