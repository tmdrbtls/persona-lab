# PersonaLab

AI 소비자의 사용 의향과 행동을 비교하고 실제 참가자 조사 결과와 함께 분석하는 제품 사전 검증 플랫폼의 프런트엔드 데모입니다.

## 배포

<https://persona-lab-blue.vercel.app>

## 로컬 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 확인할 수 있습니다.

## 주요 기능

- 스터디 대시보드와 목록
- 4단계 스터디 생성 흐름
- AI와 실제 참가자 퍼널 비교
- 의향·행동 격차 및 이탈 이유 분석
- 근거 세션 상세 보기
- 참가자 현황과 버전 비교
- 데스크톱·모바일 반응형 UI
